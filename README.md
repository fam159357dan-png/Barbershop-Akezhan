# Akezhan Barbershop

Сайт барбершопа Akezhan в Петропавловске (ул. Абая, 40). Статический, без сборки: открывается как обычная страница и работает на GitHub Pages.

## Что внутри

- Анимации: прелоадер, плавный скролл (Lenis), появление блоков при прокрутке, бегущая строка, магнитные кнопки, свой курсор на ПК.
- Прайс, мастера, галерея, слайдер отзывов из 2GIS (листается свайпом).
- Онлайн-запись: услуга, мастер, день и время собираются в готовое сообщение и открываются в WhatsApp на номер +7 707 685 72 08.
- Статус «Открыто / Закрыто» по времени Петропавловска (UTC+5).
- Контакты, карта, маршруты в 2GIS и Яндекс Картах, плавающая кнопка WhatsApp.
- Адаптив под телефоны, учитывает настройку «уменьшить движение».

## Как менять контент

Всё лежит в `data.js`:

- `services`: услуги и цены (`price: null` выводится как «уточняйте»);
- `team`: мастера, их Instagram и фото (`photo: "assets/team/sayat.jpg"`);
- `gallery`: фото и видео работ, положите файлы в `assets/gallery/` и перечислите их;
- `reviews`: отзывы.

## Запуск локально

```
python3 -m http.server 8000
```

и откройте http://localhost:8000.

## Публикация

Settings → Pages → Deploy from a branch → `main` / root.
